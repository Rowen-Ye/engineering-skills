## 性能工程 Skill

从工作负载与性能目标出发，结合理论建模、业界研究和可复现实验开展调优。覆盖多个系统领域的分析入口，提供 LLM 推理演示；示例数据为人工构造，不代表真实优化收益。

在 Codex 中输入：
